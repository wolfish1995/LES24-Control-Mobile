# LES24 Control Android — MVP

Android-клиент для существующей прошивки LES24. Прошивка прибора не меняется.

## Функции
- USB Serial 115200 через Android USB Host.
- Поддержка распространённых USB-UART мостов через usb-serial-for-android.
- Обзор AP / STA / BLE через тот же Live Analyzer, что в desktop-версии.
- Команды мониторинга 1 / 2 / 3 / 4 и выход `m`.
- Отдельный GUI `Links AP → STA`.
- Отдельный GUI `RSSI-локализация` (режим 9), включая преобразование штатной ASCII-карты в графический план.
- Сервисный терминал.
- Запись XML, совместимого с desktop LES24 Control / YAT-логом.
- EULA на первом запуске.

## Подключение
Телефон или планшет должен поддерживать USB Host/OTG. LES24 подключается через USB-C/OTG.
Приложение запрашивает системное разрешение Android на доступ к USB-устройству.

## Сборка
Проект рассчитан на:
- Android Gradle Plugin 9.3.0
- Gradle 9.5.0
- compileSdk 37
- JDK 17

В `.github/workflows/build-apk.yml` лежит готовая GitHub Actions сборка.
После успешного workflow APK публикуется как artifact `LES24-Control-Android`.

## Важно
Первый APK необходимо проверить на реальном LES24. В зависимости от аппаратной ревизии прибора USB-UART мост может отличаться (CP210x / CH34x / FTDI / CDC и т.п.). Библиотека usb-serial-for-android поддерживает основные варианты, но физическая проверка обязательна перед распространением клиентам.
